# 查看与复用

直接打开 `previews/` 下的 GIF 或 MP4，即可观看动画。最终透明图集位于 `final/spritesheet-extended.png`。

## 从成品图集重新导出预览

需要 Python 3 和 Pillow，在仓库根目录执行：

```sh
python -m pip install -r requirements.txt
python scripts/export_previews.py
python scripts/verify_archive.py
```

预览导出到 `exports/`。导出工具只裁切并编码已有图集像素，不重新生成或改变角色。

## 从源图重做制作流程

本次使用 ImageGen 生成画面，并使用 Codex Pets 插件 0.1.6 的附带制作工具提取姿势、注册、组合和验证。提示词、源图、注册结果与检查报告均保存在仓库中。

仓库未复制插件本身，也不包含图像生成服务。要从源图重新生成，需要在具备 ImageGen 和对应 Pets 插件的环境中运行。相同提示词再次生成的图片不保证逐像素相同。

推荐顺序：标准形象 → 各组动作 → 提取与逐组检查 → 标准动画图集 → 四个主要视线方向 → 两组方向姿势 → 最终图集 → 一次清边 → 结构/视觉/方向检查 → Pets 官方预检 → 上传创建。

修改某组动作时，重新生成和验证该组，再组合完整图集。修订视线时应修订整组连续姿势，避免单独替换一个方向带来画风或比例跳变。

## 文件完整性

`artifact-manifest.json` 记录本次整理的制作产物及 SHA-256。公开版报告中的本机绝对路径转换为相对路径，因此文字报告的字节值可能与原本地报告不同；PNG 成品像素与原始验证文件完全一致。
